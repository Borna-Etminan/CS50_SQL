# CS50 SQL (Persian)

> **Official Persian translation of Harvard University's CS50 SQL course, created under the CS50x Persian community.**

## 📖 About This Project

This repository serves as the official GitHub repository for the **Persian edition of Harvard University's CS50 SQL** course.

It contains project resources, and updates related to the course. The complete Persian course, including professionally translated video lessons, educational content, exercises, and learning resources, is available through the official **CS50x Persian** platform.

This project is published under the guidance of **Harvard University** and the **CS50x Persian** team.

## 📚 What You'll Learn

Throughout this course you will learn:

* Introduction to Databases
* Relational Databases
* SQL Syntax
* Filtering & Sorting Data
* Aggregate Functions
* Joins
* Subqueries
* Database Normalization
* Indexes
* Views
* Transactions
* Data Modeling
* Query Optimization
* Real-world SQL Problem Solving

By the end of the course, you'll have the skills required to confidently work with relational databases and SQL in real-world applications.
